# n1zamrus-mathee

Учебный пет-проект Open-ED о решении квадратных уравнений. Репозиторий
предназначен для небольших практических задач: здесь можно последовательно
добавлять математическую логику, тесты и инструменты разработки.

## Возможности

- решение квадратных уравнений с двумя действительными корнями;
- обработка одного кратного корня и отсутствия действительных корней;
- поддержка вырожденного линейного уравнения;
- автоматические unit-тесты на стандартной библиотеке Python;
- запуск проверки через Makefile и CI.

Основная функция проекта находится в `quadratic.py` и называется
`solve_quadratic(a, b, c)`. Она возвращает действительные корни уравнения
`a*x**2 + b*x + c = 0` в возрастающем порядке.

## Требования

- Python 3.9 или новее;
- GNU Make;
- Git.

Внешние Python-зависимости не нужны.

## Установка

Клонируйте репозиторий и перейдите в его каталог:

```bash
git clone https://github.com/N1zamRus/n1zamrus-mathee.git
cd n1zamrus-mathee
```

Проверить доступность инструментов можно командами:

```bash
python3 --version
make --version
```

## Использование

Функцию можно вызвать из Python:

```python
from quadratic import solve_quadratic

roots = solve_quadratic(1, -3, 2)
print(roots)  # (1.0, 2.0)
```

Для запуска всех проверок используйте:

```bash
make test
```

Уравнение с `a == 0` обрабатывается как линейное. Для нулевого уравнения,
имеющего бесконечно много решений, функция выбрасывает `ValueError`.

## Тестирование

Локальная проверка перед отправкой изменений:

```bash
make test
```

Тесты проверяют два действительных корня, кратный корень, отсутствие
действительных корней, линейный случай и обработку нулевого уравнения. CI
запускает ту же команду на каждый пулл-реквест.

## Вклад в проект

1. Создайте форк репозитория.
2. Создайте отдельную ветку для задачи.
3. Внесите небольшие тематические изменения и добавьте проверку результата.
4. Запустите `make test` локально.
5. Откройте пулл-реквест в этот репозиторий.

В описании пулл-реквеста укажите `Resolve #N`, где `N` — номер issue. Не
записывайте изменения напрямую в `main`.
